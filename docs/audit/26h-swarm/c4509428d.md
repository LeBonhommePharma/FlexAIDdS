# Audit: c4509428d — Add: FlexAID A/B0/B pilot harness for three-engine campaign

## Summary (2-4 sentences)
Commit `c4509428dd3901863766b5af1066a30520123a13` introduces the classic FlexAID **A / B0 / B** pilot harness for the three-engine campaign: `generate_flexaid_inp.py` (ProcessLigand + CONFIG/ga), thin wrappers `run_{A,B0,B}_pilot8.sh`, shared launcher `run_flexaid_arm_pilot8.sh`, prepare helper, and `parse_flexaid_arm_results.py`. At **this** SHA, arm definitions are **TEMPER 0 / 0 / 298** with **CLUSTA CF / CF / FO**, matched **pop=1000 gen=6000 R=5**, seed_base **20260714**, and matrix MD5 pin **`72d7c7396702331d96ff12d18f831796`** — aligned with the then-current `three_engine_entropy_comparison.md` (TEMPER **298**, not the later TEMPER **21** freeze). The harness is a solid protocol skeleton with real matrix gates and no-seed GA init, but has several fair-compare and claim-readiness holes: non-reproducible seeds on staged A/B binaries, CF-only election of “top1” even for entropy arm B, smoke→pilot8 budget contamination (fixed ~10 min later), forced live iCloud OUT, no PoseBusters/S2, and zero tests.

## Severity: HIGH

Not a build-break; it is the first live path for A/B0/B science runs. Mis-election and seed non-determinism can silently poison headline S1 rates if treated as claim-ready without the later fixes.

## Findings (detailed)

### F1. Cross-restart election is always CF, including arm B (HIGH)

- **Evidence:** `parse_flexaid_arm_results.py` elects `best` by `cf_app` (else `cf`) among `{pdb}_r*_0.pdb`. No free-energy / mode soft-β field is read. Arm is only a CSV label.
- **Why it matters:** Arm B’s science claim is entropy (soft-β) ranking **on**. Electing the restart with best CF.app re-implements B0 logic at the campaign layer. Headline `rmsd_top1` / `success_s1` for B can look like CF docking even when each restart’s `_0.pdb` was FO-ranked.
- **Fix:** For arm B, elect by engine mode order already in filenames **or** parse FO/thermo REMARK if present; at minimum elect **per-restart rank-0 as-is** (e.g. best RMSD among rank-0 is diagnostic-only; primary S1 should be rank-0 of a designated restart or majority vote). Document election rule in protocol. Prefer shared-ensemble re-rank for pure B0→B.

### F2. Seed reproducibility is documented as broken for staged binaries (HIGH)

- **Evidence:** Generator docstring: “staged FlexAID A/B binaries seed with time(0); STRTSEED … may be ignored.” `meta.json` `seed_limitation`; receipt `seed_note`. Modern tree `gaboom.cpp` **does** parse STRTSEED (~3528), so limitation is **binary-pin dependent**.
- **Why it matters:** Protocol receipt lists `seed_base: 20260714` and five seeds — auditors will assume determinism. Fair A vs B0 comparison under independent time-based RNG is noisy; cannot reproduce a single restart.
- **Fix:** SHA256-pin binaries that honor STRTSEED, or patch staged pins; echo seed from binary logs into receipt; refuse claim if log seed ≠ STRTSEED. Do not set `protocol_claim_eligible=1` without seed attestation.

### F3. Smoke OUT shares pilot8 path → budget contamination (HIGH at this SHA)

- **Evidence:** `SMOKE=1` only shrinks POP/GEN/R and target list; `OUT` stays `…/pilot8`. Skip if `result.csv` exists. Commit message proudly notes “B0 smoke on 1GPK … exit 0” — that tiny-GA CSV would block full pilot for 1GPK.
- **Why it matters:** Violates matched budget; silent under-search in headline pilot.
- **Fix:** Landed in `d7fc2afaa` (separate `…/smoke/`). Operators on pure c4509428d trees must `--force` or delete smoke CSV before pilot.

### F4. TEMPER 298 here ≠ TEMPER 21 later (MEDIUM — chronology)

- **Evidence:** `ARM_SPEC["B"]["temper"] = 298` vs later protocol/3Dsig **21**. Engine: T is **effective softmax temperature** over unitless CF (`β=1/T`), so 21 vs 298 **strongly** changes mode weights (not a cosmetic label).
- **Why it matters:** Mixing receipts across the freeze invalidates B and red-pair medians.
- **Fix:** Receipt must record `temper` (this commit’s RUN_RECEIPT records pop/gen/restarts but **not** TEMPER/CLUSTA — gap). Tag campaign dirs `B_temper298` vs `B_temper21`.

### F5. RUN_RECEIPT omits TEMPER / CLUSTA / seed_base (MEDIUM)

- **Evidence:** Receipt fields: run_id, arm, started_utc, output, storage, pop, gen, restarts, targets, matrix_md5, binary_sha256, binary, smoke, seed_note. **No** temper, clusta, seed_base, sphere MD5, ProcessLigand path.
- **Why it matters:** Matrix pin alone is insufficient to reconstruct arm definition after TEMPER drift.
- **Fix:** Add `temper`, `clusta`, `seed_base`, `seeds[]`, `sphere_source`/`sphere_md5`, `maxres`, `n_flex_bonds` from meta.json.

### F6. PoseBusters / S2 / thermodynamic columns empty (MEDIUM)

- **Evidence:** Parser sets `success_s2=""`, `pb_pass=""`, `H/TS/F=""`, `tencom_status="NA"`. Docstring correctly: “Does not claim PoseBusters or thermodynamic ΔG.”
- **Why it matters:** Good honesty locally; bad if aggregator treats blank S2 as pass or plots F. AGENTS.md: success needs RMSD≤2 **and** PB for benchmark claims.
- **Fix:** Leave fail-closed in aggregators; wire optional `bust` later; never promote S1-only as campaign success in ops copy.

### F7. No tests for generator or parser (MEDIUM)

- **Evidence:** Commit is scripts-only; no `tests/` or pytest coverage of ARM_SPEC TEMPER/CLUSTA pairs, matrix gate, seed function, or CSV schema.
- **Why it matters:** Drift of arm defs (298→21) and election logic will not be CI-caught (later commits show this drift happened in-tree).
- **Fix:** Pure-Python unit tests: ARM_SPEC defaults; write_config lines; stable_seed determinism; parse election with fixture PDBs; matrix pin mismatch raises.

### F8. Site definition can silently degrade (MEDIUM)

- **Evidence:** `find_sphere_file` order: `FLEXAIDDS_SPHERE_ROOT` → queue inputs `*sph*`/`*cleft*` → hardcoded iCloud cavities path → **`{PDB}_site.pdb` fallback** with warning file only.
- **Why it matters:** Fair compare requires identical LOCCLF definition across arms and vs C. Site atoms ≠ GetCleft spheres.
- **Fix:** Fail closed unless sphere file has radius-bearing ATOM/HETATM from GetCleft; require explicit `--allow-site-fallback`.

### F9. Hygiene / storage policy (LOW–MEDIUM)

- **Evidence:** Hard default OUT under Mobile Documents; REPO fallback `git -C "${HOME}/Projects/FlexAIDdS"`; no `scripts/check_repo_hygiene.py` delta. ProcessLigand resolution is env-first (good).
- **Why it matters:** AGENTS.md local-first / thin-iCloud; CloudDocs hash/write hangs.
- **Fix:** Later commits (`5a24ebbd2`, `ab0850a6d`, local-first helpers) address OUT. Prefer repo-relative REPO only.

### F10. CF / entropy language mostly careful (LOW / positive)

- **Evidence:** Labels say “CF” vs “TEMPER 298”; parser does not invent ΔG; meta notes seed limitation. Engine comments (tree) clarify β=1/T soft-β.
- **Residual:** Arm B label “entropy” without soft-β tilde can be over-claimed in talks; election bug (F1) makes the label even more misleading in metrics.

### F11. Ranking path / GA search identical within budget (INFO)

- **Evidence:** Same NUMCHROM/NUMGENER/rates for all arms; only TEMPER/CLUSTA and binary differ. No change to Voronoi CF matrix beyond pin. Does **not** alter C0/C DatasetRunner ranking.
- **Impact:** Within classic arms, search effort is fair; ranking divergence is intentional via TEMPER/CLUSTA (subject to F1).
