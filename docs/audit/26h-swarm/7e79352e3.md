## 5. Ranking neutrality — deep findings

AGENTS.md: *“Preserve current ranking. Do not alter pose ranking, clustering, or output order unless the user explicitly requests…”*

This merge must be split into **(A) PoseBust path** and **(B) co-landed docking stack**.

### 5.1 PoseBust path — **ranking-neutral (PASS)**

Call order in `DatasetRunner` (merge tree):

1. Multi-restart GA + emission  
2. **Election** (`select_pose_freq_gated_pooled` ± optional consensus / BCR) → `elected_pose_pdb`  
3. Atomic copy → `elected_pose.pdb` + SHA256  
4. **Authoritative RMSD** recomputed from elected artifact → `success_rmsd`  
5. **Then** PoseBust block: extract ligand, optional NativePoseQC, default `run_upstream_bust` → `pb_pass`  
6. `success_pb = success_rmsd && pb_pass`  
7. Hash re-check can **force `pb_pass = false`** if elected bytes mutated — still does **not** pick another pose  

Comments in DatasetRunner: candidate RMSD “diagnostic only and never affects retention”; validators “tied to the final immutable elected artifact.”

**No code path** feeds `pb_pass` / NativePoseQC scores back into:

- GA fitness / selection  
- `cluster()` emission order  
- `select_pose_freq_gated*` CF/frequency ranking  

→ **PoseBust as a module is ranking-neutral.**

### 5.2 Co-landed docking stack — **not ranking-neutral (FAIL for full merge)**

#### R1 — Cluster ACF / emission order (`LIB/cluster.cpp`) — **HIGH**

Parent used a **global** shifted-Boltzmann partition function to accumulate per-cluster `Clus_ACF` (energy + entropy-style terms when `FA->temperature`).

Merge replaces that with **cluster-local log-sum-exp free energy**:

```text
Clus_ACF = local_origin − log(local_z) / β
```

with membership still via RMSD clustering (`Clus_GAPOP`), then `QuickSort_Clusters` on ACF when `T>0`.

Also removes `GAPOP` parallel swaps from `QuickSort_Clusters` / `swap_clusters` (membership arrays no longer co-sorted with rank arrays — membership remains indexed by chromosome, not by cluster rank slot).

**Effect:** When classic entropy emission is active (`T>0` && `!force_cf_rank_emission`), **rank-0..N PDB emission order can change** vs parent for the same ensemble. This is an intentional basin free-energy reformulation, not a no-op refactor.

#### R2 — Intermolecular hard clash during CF (`LIB/Vcontacts.cpp` + `soft_wall.h`) — **HIGH when enabled**

- New `posebusters_vdw_radius` + `violates_relative_vdw_cutoff`.
- Protein–direct-ligand pairs can set `*clash_value = CLASH_THRESHOLD` when `d < ratio · (r_i+r_j)`.
- Defaults: `intermolecular_clash_ratio = 0.0` in `config_defaults.h` / parser → **disabled** for bare configs.
- **DatasetRunner campaign dock JSON** writes `"intermolecular_clash_ratio": 0.75` → **enabled on the benchmark path**.

**Effect:** Search landscape and retained chromosomes change for campaign runs; clash-rejected poses never compete on soft-wall CF. This is **search-time** scoring change aligned with PoseBusters geometry, not post-hoc labeling.

#### R3 — Multi-restart election default (`DatasetRunner`) — **MEDIUM**

`FLEXAIDDS_CONSENSUS_SCORER` default flipped **1 → 0**.

Parent: consensus re-rank on by default when ≥2 restarts.  
Merge: consensus **off** unless env set; keeps freq-gated min-CF election.

**Effect:** Different elected rank-0 for multi-restart campaigns with identical GA outputs.

#### R4 — Coarse init / gen-0 ranking (`coarse_init.cpp`) — **MEDIUM**

- Ranks seeds by full apparent CF (`get_apparent_cf_evalue`) instead of attractive `cf.com` alone.
- Deterministic sort of seed indices; spatial diversity changes.
- Comments explicitly reject interpenetrating “false CF” seeds.

**Effect:** Different gen-0 population → different GA trajectory and eventual cluster ranks.

#### R5 — Exact-pose rescore before cluster (`top.cpp`) — **MEDIUM**

Replaces prior H-bond rank rescore path with exact-pose rebuild audit; fail-closed overwrite of chromosome CF/evalue when delta > 1e-4.

**Effect:** Emission CF / ranking inputs can differ when search score ≠ rebuilt pose score.

#### R6 — No-seed cognate geometry (`DirectLigandIC`, `top`, readers, site PDBs) — **HIGH (protocol)**

Blind / no-seed cognate redock changes what is allowed as start state and how ligand IC is built. This is a **protocol class change**, not a pure validator. Ranking of poses under the old seeded protocol is not comparable without controlling seeds.

#### R7 — Success label vs rank order

- Legacy `result.success` remains **RMSD gate only** (`== success_rmsd`).
- New `success_pb` / `claim_ready` stack adds PoseBusters **without rewriting pose order**.
- Success **labels** change (stricter claims); **order of `_0.pdb`, `_1.pdb`, …** is governed by R1–R6, not by PB.

| Layer | Neutral vs `8772039e7`? | Notes |

| `success_pb` column | **Yes** (order) / **No** (metrics) | Does not re-elect |

- **PoseBust-only claim of ranking neutrality: PASS.**
