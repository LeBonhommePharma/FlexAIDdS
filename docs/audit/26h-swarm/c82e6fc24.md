## Findings

### F1. Soft-β algebra is correct; \(\tilde G \equiv\) local ACF (PASS with caveats)

**Evidence — DatasetRunner (commit / current):**
```cpp
// Z_loc with Emin shift; p_i = exp(-(e-Emin)/T)/Z
// return H - T * S;  // G̃
```
(`LIB/DatasetRunner.cpp` ~997–1032)

**Evidence — cluster ACF (engine emission when `T>0`):**
```cpp
Clus_ACF[...] = local_origin - std::log(local_z) / FA->beta;
// FA->beta = 1/T  (read_input.cpp / config_parser.cpp TEMPER)
```
(`LIB/cluster.cpp` ~168–183; `LIB/read_input.cpp` ~245–255)

**Identity (soft-β \(\beta=1/T\), no \(k_B\)):**
\[
p_i=\frac{e^{-E_i/T}}{Z},\quad
\tilde S=-\sum p_i\ln p_i,\quad
\tilde H=\sum p_i E_i
\quad\Rightarrow\quad
\tilde G=\tilde H-T\tilde S=-T\ln Z=E_{\min}-T\ln Z_{\mathrm{loc}}.
\]
Numerical check on synthetic ensembles at \(T=21\) and \(T=298\): absolute difference \(0\).

**Caveats (do not confuse with “done”):**
1. Identity requires **same member energies** and **same \(T\)** as the engine layer.
2. This is a **CF scoring-proxy** soft free energy, **not** experimental \(\Delta G\), not StatMechEngine Helmholtz with \(k_B\).
3. BindingMode classic path is **not** the same objective (see F4).

**Science impact:** Formula itself is the right 3Dsig-style soft-β object. Implementation gaps below break equivalence in production.

**Fix:** Keep algebra; share one implementation (`SoftBetaFreeEnergy.h` — not on main; see F10); unit-test identity + rank order vs ACF.

### F4. Layers do **not** share one ranking objective (HIGH)

Commit message / docs claim DatasetRunner S1 matches “classic FlexAIDdS” / BindingMode / ACF.

| Layer | Objective | \(T\) | Ensemble | Vib / NATURaL |
|-------|-----------|-------|----------|---------------|
| `cluster.cpp` ACF | Local \(E_{\min}-T\ln Z_{\mathrm{loc}}\) on **app_evalue** | dock TEMPER | CF-cluster members | No |
| `BindingMode::compute_energy` classic | \(\tilde H-T\tilde S\) with **global** \(p_i=w_i/Z_{\mathrm{global}}\) + **vib** + natural ΔG | Population Temperature | All poses in mode, global Z | Yes |
| DatasetRunner soft_free_energy | Local \(\tilde H-T\tilde S\) on **`.mcf` or head CF** | **298 default** | `.mcf` only | No |

**BindingMode global-Z detail** (`LIB/BindingMode.cpp` ~296–350, ~868–871):
- \(w_i=\exp(-E_i/T)\) on **app_evalue**.
- \(p_i=w_i/Z_{\mathrm{global}}\) (entire BindingPopulation), not mode-local Z.
- Ranking energy adds `compute_vibrational_correction()` and NATURaL ΔG.

That is **not** \(\tilde G_{\mathrm{local}}\) and **not** ACF. Docs saying “Same \(\tilde G\)” across layers are false at this commit (and still false on main without SoftBeta wire-up).

**FO REMARK CF vs soft-β energy:** FO writes `REMARK CF=` from **evalue**, `CF.app` from **app_evalue** (`BindingMode.cpp` ~599–601). Election parses **CF=** (evalue). Engine soft-β / ACF / `.mcf` use **app_evalue**. Proxy mismatch for FO S1 when `.mcf` absent.

**Fix:** Single shared local soft-β primitive; BindingMode mode sort must use **mode-local** Z for classic ranking if 3Dsig contract is local ACF; DatasetRunner must prefer CF.app / app_evalue consistently; vib only behind documented flag.
