## 4. GPL risk analysis

### 4.1 What this commit does *right*

- Reasserts clean-room policy for pose validation (subprocess-only BSD tool).
- Keeps NRGRank listed as GPL inspiration / not a dependency in matrix and TPL (historical stance).
- Does not add any GPL dependency, header, or vendored tree.
- Collapses dual `THIRD_PARTY_LICENSES.md` (docs path → root) reducing drift risk for the *canonical* dependency list.

### 4.2 Repo residual — **HIGH (pre-existing; docs overclaim)**

#### H1 — NOTICE / TPL vs NRGRank-derived source in `LIB/`

**NOTICE (this commit) states:**

> NRGRank (GPL-3.0) is cited as scientific inspiration only. **No NRGRank source is included.**

**`THIRD_PARTY_LICENSES.md` still states:**

> FlexAID∆S and FreeNRG do **NOT** import, link to, or incorporate NRGRank code  
> Clean-room implementation… Independent implementation from mathematical descriptions

**Tree evidence (present at and after this commit):**

| Artifact | Header claim | SPDX on file | Build linkage |
|----------|--------------|--------------|---------------|
| `LIB/CoarseScreen.h` | “**C++20 translation of NRGRank’s `process_target.py` + `rank_molecules.py`**” | Apache-2.0 | `test_coarse_screen` only (not `flexaid_core`) |
| `LIB/CoarseScreen.cpp` | Same paper citation; includes `nrgrank_matrix.h` | Apache-2.0 | tests |
| `LIB/nrgrank_matrix.h` | “**From: NRGRank** … Matrix: `MC_5p_norm_P10_M2_2_multiplied_2`” + full 41×41 numerical matrix | Apache-2.0 | via CoarseScreen tests |
| `LIB/TwoStageScreen.h` | Stage 1 = NRGRank coarse-grained screening | Apache-2.0 | tests |

Namespace used: `nrgrank::`.

**Why this matters for Apache purity**

- Translating GPL Python into C++ and shipping it under Apache SPDX is **not** a clean-room strategy; it is a classic GPL contamination vector (derivative work risk).
- Embedding a named energy matrix “From: NRGRank” is **data/expression** that may be protected independent of algorithm ideas.
- Even if main docking binaries do not link CoarseScreen today, **the source is in the public Apache-2.0 tree** and is compiled in the test suite when `BUILD_TESTING` enables that target — redistributors of the full source tarball receive it.
- Stale isolation checklist (`docs/licensing/PHASE1_GPL_ISOLATION_CHECKLIST.md`) still claims grepping `NRGRank` under `LIB/` should find **zero** hits — false at this commit.

**This commit did not create CoarseScreen**, but it **reaffirmed** the absolute “no NRGRank source” claim in a brand-new `NOTICE`, which is the wrong place to overclaim. Severity for the *repo*: **HIGH**. Severity for the *docs commit intent* (PoseBust): orthogonal, but the NOTICE sentence is still wrong.

**Remediation directions (out of scope for this audit’s “no source edits” mandate; for maintainers):**

1. Rewrite NOTICE/TPL to describe actual status (e.g. experimental Apache reimplementation under legal review; or quarantine path; or remove/replace units).
2. Prefer: isolate behind a non-default, non-distributed path **or** replace with independently regenerated parameters under clear FlexAID/NATURaL provenance **or** obtain dual-license / permission from NRGRank copyright holders.
3. Never describe a “translation of process_target.py” as Apache-clean without counsel sign-off.
4. Refresh PHASE1 checklist or mark historical.

#### H2 — Policy wording tension (pre-existing)

- `AGENTS.md` / `CLAUDE.md`: “no GPL … even as inspiration” (strict).
- `clean-room-policy.md` / TPL: ideas/algorithms from GPL ecosystems OK; code expression not.

This commit does not resolve that tension; it only extends clean-room text for PoseBust (which is the *correct* use of the ideas-vs-expression rule for a BSD optional tool + original C++).

### 4.3 Other GPL markers

- Repo-wide `GPL|AGPL` hits in **docs / agent instructions / TPL** are intentional policy text, not licensed code.
- `scripts/check_licenses.py` + `.github/workflows/license-scan.yml` (scancode) forbid GPL/AGPL/LGPL SPDX keys — good CI backstop; **will not** catch “translated from GPL without a GPL header” if files are marked Apache-2.0.
- OpenMP note (GCC runtime exception) remains correctly caveated in TPL.
- **No** GPL license headers found under `LIB/` source (scancode-style string search). Risk is **unmarked derivative** content, not mislabeled GPL headers.

### 4.4 PoseBust-specific GPL risk

**None material.** PoseBusters is BSD; NativePoseQC is first-party Apache; no GPL cheminformatics stack is linked for the native path.
