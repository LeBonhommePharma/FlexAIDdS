### F1. Live tarball SHA-256 matches formula (PASS — critical for this audit)

- Evidence (this session):
  ```bash
  curl -fsSL -o v2.0.3.tar.gz \
    https://github.com/LeBonhommePharma/FlexAIDdS/archive/refs/tags/v2.0.3.tar.gz
  shasum -a 256 v2.0.3.tar.gz
  # 6c8442fc672a127db354ff3b6e08a2252e8c921372d902d062ecbf4296aef186  v2.0.3.tar.gz
  ```
  - Size: **66002413** bytes; `file`: gzip compressed Unix data.
  - Archive root: `FlexAIDdS-2.0.3/` (GitHub tag-archive naming convention).
  - Formula at merge: same 64-char lowercase hex.
  - PR #268 body: same digest, claimed “verified twice.”
  - Leaf commit message documents the same `curl | shasum -a 256` recipe.
- Why it matters: Homebrew refuses (or worse, would silently accept wrong content if mis-pinned) stable installs when `sha256` ≠ downloaded archive. Wrong digest is a **distribution-blocker**; correct digest is the whole point of this merge.
- Fix recommendation: **None.** Digest is correct against the live GitHub tag archive as of this audit.
