## 5. Findings list (consolidated)

### F1. Subject understates diff: ships `v130_watch.py` (LOW)

- Evidence: `git show --stat` → `.gitignore` + new 124-line Python file; subject only mentions ignore residue.
- Why it matters: Auditors and bisect treat this as “gitignore hygiene”; ops/science reviewers may miss absolute-path and RMSD-only issues.
- Fix: Prefer split commits (`chore(gitignore): …` vs `ops: v130 progress watcher`) or expand the message body to list the watcher.

### F2. Gitignore effectively covers live Astex repro residue (PASS / intentional)

- Evidence: Live ignored set includes `full_v128`–`full_v132`, `full_PREFIX_tokenize_0015`, `smoke_*`, `v130*.log|pid`, `spheres/`, `engine/`.
- Why it matters: Directly reduces results-risk and dirty-tree noise after multi-day campaigns.
- Fix: Optional tighten — `benchmarks/astex_repro/**/*.pid`, `**/result.csv` under non-canonical OUT names, or document allowed OUT prefixes.

### F3. Hardcoded `/Users/lp.more/...` in new tracked script (MEDIUM)

- Evidence: `BASE = "/Users/lp.more/Projects/FlexAIDdS/benchmarks/astex_repro"` at L12 of `v130_watch.py`.
- Why it matters: AGENTS.md non-negotiable hygiene; script is dead on any other checkout path; embeds local username in git history.
- Fix: `BASE = Path(__file__).resolve().parent` (same style as `score_offline.py` / `score_reference.py` already in the tree). Optionally `os.environ.get("FLEXAIDDS_ROOT", ...)`.

### F4. Stale hardcoded PIDs (MEDIUM for ops usefulness)

- Evidence: `V130_PID = 98837`, `QUEUE_PID = 6618`.
- Why it matters: Watcher liveness is wrong within hours of process recycle; false DEAD alarms.
- Fix: Read `Path(BASE)/"v130.pid"` and `v130_1hq2.pid` (now gitignored — correct) with fallback to CLI args.

### F5. RMSD-only “success” label (MEDIUM if used for claims; LOW if local scratch only)

- Evidence: bins `rmsd < 2.0` → success; no PoseBusters / PB columns.
- Why it matters: Benchmarking contract forbids RMSD-only claim success.
- Fix: Label UI as `rmsd_ok` / `pose_rmsd_tier`, not `success`; or join PB status when present in `result.csv`.

### F6. Redundant / incomplete ignore edges (LOW)

- Evidence: duplicate `**/*.bak`; nested pid gap; non-`full_*` OUT names trackable; `full_v130.tgz` trackable.
- Fix: Deduplicate; add `**/*.pid`; consider `*.tgz` under `astex_repro/` or document archive policy.

### F7. Hygiene checker blind spot (LOW–MEDIUM process)

- Evidence: `scripts/check_repo_hygiene.py` `SCAN_PREFIXES` excludes `benchmarks/` and most `scripts/`.
- Why it matters: Parent launchers + this watcher pass “hygiene OK” while violating the prose rule in AGENTS.md.
- Fix: Extend scan to `benchmarks/**/*.py` and `scripts/**` (or allowlist disposable `astex_repro/launch_*` with a tracked exception list — prefer fixing paths).

### F8. No secrets introduced (PASS)

- Evidence: clean secret pattern scan on commit diff; env ignores unchanged.
- Fix: N/A.
