FlexAIDdS — Entropy-driven molecular docking

Usage:
  .swarm/cmaes/orchestrator/build_fast/FlexAIDdS <receptor> <ligand> [options]

  Files can be in any order. FlexAIDdS auto-detects which is
  the receptor and which is the ligand from file content.

  Receptor: .pdb, .cif, .mmcif (protein/nucleic acid)
  Ligand:   .mol2, .sdf, .mol, .pdb (small molecule)
            or a SMILES string directly on the command line

  .swarm/cmaes/orchestrator/build_fast/FlexAIDdS --legacy <config.inp> <ga.inp> <output_prefix>

Options:
  -c, --config <file.json>   JSON config (overrides defaults)
  -o, --output <prefix>      Output prefix (default: flexaid_out)
  --backend <cpu|metal|webgpu>  GPU compute backend for CF scoring (default: cpu)
  --rigid                    Fast rigid-body screening
  --screen                   NRGRank coarse-grained screening mode
  --screen-top-n <N>         Return top N from coarse screen (default: 100)
  --parallel-dock            Grid-decomposed parallel docking (ParallelDock)
  --parallel-dock-regions <N> Number of spatial regions (default: 128)
  --campaign                 Parallel virtual screening campaign mode
  --folded                   Skip NATURaL chain growth
  --legacy                   Legacy 3-file input mode
  --benchmark <set>          Run benchmark dataset (astex, casf2016, etc.)
  -h, --help                 Show this help

Library input (virtual screening):
  Ligand can be a multi-molecule SDF, a SMILES file (.smi),
  or a directory of MOL2/SDF files. Each ligand is docked
  independently against the receptor.

Multi-model receptor (NMR / cryo-EM / MD):
  PDB with MODEL/ENDMDL records or multi-model CIF.
  Each model is used as a separate receptor conformer.
  Results are combined via Boltzmann ensemble consensus
  with reference entropy correction.
