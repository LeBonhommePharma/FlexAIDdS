What is an Entropy Audit?

An entropy audit independently recomputes the configurational thermodynamic quantities reported by a docking engine from the underlying pose ensemble.

The core quantities audited are:

  • F_config — configurational free energy derived from the sampled partition function
  • S_config — configurational entropy
  • TotalSampledPartitionFunction — the finite-sample partition function used in the original analysis

Audits are performed using the same statistical mechanics formalism implemented in the reference engine (see statmech.cpp and BindingMode.cpp) but executed as an independent verification step on deposited or publicly archived pose data. Results and full methodology are published for community scrutiny.

Why it matters (the entropy gap)

Conventional docking scoring functions routinely neglect or approximate the configurational entropy term. This produces a systematic bias that favors rigid, enthalpically dominated poses and under-ranks binding modes in which entropy makes a substantial contribution.

The result is an “entropy gap” between the quantities reported by the docking tool and the true thermodynamic profile of the system. Independent public audits close this gap by supplying reproducible, engine-agnostic values for F_config, S_config, and the partition function against which original reports can be compared.

These audits do not replace the original docking campaign; they provide an external consistency check required for credible use of docking results in downstream decision-making, especially in psychopharmacology and structure-based design.
